# Student Database Management System (C++)

A simple console-based Student Database Management System developed using C++. It allows users to manage student records through basic database operations.

## Features
- Add Student Records
- Search Students by ID
- Delete Student Records
- Display All Students

## Technologies Used
- C++
- Object-Oriented Programming (OOP)
- Classes and Objects
- Vectors and Strings

## How to Run

Compile using GCC:

```bash
g++ main.cpp -o student_db
```

Run:

```bash
student_db.exe
```
