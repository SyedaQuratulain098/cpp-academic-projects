# Library Management System (C++)

A simple console-based Library Management System developed using C++. It allows administrators to manage books and student records, while students can manage their accounts, deposit money, and borrow books.

## Features
- Admin and Student Login
- Add and Edit Books
- View Book Availability
- Student Registration
- Check Student Balance
- Deposit Money
- Borrow Books
- Sort Student Records

## Technologies Used
- C++
- Arrays and Functions
- Loops and Conditional Statements
- Searching and Sorting
