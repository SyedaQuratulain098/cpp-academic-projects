# C++ Academic Projects

This repository contains academic projects developed using C++. These projects demonstrate basic programming concepts, object-oriented programming (OOP), and problem-solving skills.

## Projects

### 1. Student Management System
A simple console-based application for managing student records.

**Features:**
- Add new students
- Search students by ID
- Delete student records
- Display all students

**Technologies:** C++, OOP, Classes, Vectors

[View Project](./Student-Management-System/)

### 2. Library Management System
A console-based application for managing library books and student accounts.

**Features:**
- Admin and student login
- Add and edit books
- View available books
- Register students
- Deposit money and check balances
- Borrow books

**Technologies:** C++, Arrays, Functions, Loops, Conditional Statements

[View Project](./Library-Management-System/)
